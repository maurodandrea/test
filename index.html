Il video viene renderizzato in WebM 1280×720 direttamente nel tuo browser e scaricato sul tuo computer. Nessun server, nessun upload, nessun limite. YouTube accetta i file WebM nativamente.

💡 La narrazione vocale (TTS del browser) è solo in anteprima: per il voiceover nel video registra l'audio o caricalo in fase di montaggio su YouTube.
API immagini: picsum.photos (gratis, senza chiave) Musica: Web Audio API Render: Canvas + MediaRecorder Hosting: GitHub Pages
Formato 1280×720, quello richiesto da YouTube. Testo grande, contrasto alto e una faccia o emoji aumentano il CTR.
I suggerimenti sono generati localmente analizzando il tuo script: titoli alternativi, descrizione ottimizzata, tag e capitoli con timestamp basati sulla durata delle scene.
I progetti sono salvati nel localStorage del browser: restano disponibili anche dopo aver chiuso la pagina.
VidGen — open source, zero costi: API gratuite senza chiave + GitHub Pages. Fatto con Canvas, Web Audio e MediaRecorder.
